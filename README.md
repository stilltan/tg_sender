# 🚀 Telegram Sender Bot

Бот для рассылки сообщений в Telegram с управлением контактами и статистикой.

## 📋 Возможности

- ✅ Управление контактами (добавление, удаление, статусы)
- 📥 Импорт контактов из Google Sheets и CSV
- 📝 Создание шаблонов сообщений
- 📤 Запуск рассылок с настраиваемыми задержками
- 📊 Статистика и аналитика
- 👥 Множественные администраторы
- 🔔 Уведомления о статусе рассылок

## 🛠 Быстрый старт (Windows)

### 1. Получите токен бота

1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте `/newbot`
4. Следуйте инструкциям
5. Скопируйте токен

### 2. Получите ваш Telegram ID

1. Найдите @userinfobot в Telegram
2. Отправьте `/start`
3. Скопируйте ваш ID

### 3. Установите и запустите

```bash
# Склонируйте репозиторий
git clone https://github.com/stilltan/tg_sender.git
cd tg_sender

# Запустите setup (создаст venv и установит зависимости)
setup.bat

# Запустите бота
start.bat
```

## 📖 Подробная инструкция

### Настройка .env файла

После запуска `setup.bat` откроется файл `.env`. Заполните его:

```env
# Токен бота от @BotFather
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# Ваш Telegram ID (от @userinfobot)
SUPER_ADMIN_ID=123456789

# Опционально: ID группы для уведомлений
ADMIN_GROUP_ID=
```

### Импорт контактов

#### Из Google Sheets:

1. **Настройте Google API:**
   - Перейдите на https://console.cloud.google.com/
   - Создайте проект
   - Включите Google Sheets API
   - Создайте сервисный аккаунт
   - Скачайте JSON ключ
   - Сохраните как `credentials.json` в папке проекта

2. **Поделитесь таблицей:**
   - Откройте вашу Google Таблицу
   - Нажмите "Настройки доступа"
   - Добавьте email сервисного аккаунта (из credentials.json)
   - Дайте доступ "Читатель"

3. **Запустите импорт:**
   ```bash
   # Активируйте venv
   venv\Scripts\activate.bat
   
   # Импортируйте контакты
   python tools/import_gsheets.py "https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit"
   ```

#### Из CSV файла:

1. **Подготовьте CSV файл:**
   ```csv
   username,name,description
   user1,Имя 1,Описание 1
   user2,Имя 2,Описание 2
   ```

2. **Запустите импорт:**
   ```bash
   python tools/import_gsheets.py contacts.csv --group my_contacts
   ```

#### Через бота:

1. Запустите бота: `/start`
2. Нажмите "📋 Контакты"
3. Нажмите "➕ Добавить контакт"
4. Отправьте username: `@username` или `t.me/username`
5. Можно добавить несколько: каждый с новой строки

### Работа с ботом

#### Основные команды:

- `/start` - Главное меню
- `/help` - Справка
- `/stats` - Быстрая статистика
- `/add_admin ID` - Добавить администратора
- `/cancel` - Отмена текущего действия

#### Рассылка сообщений:

1. **Создайте шаблон:**
   - Нажмите "📝 Шаблоны" → "➕ Создать шаблон"
   - Введите название и текст сообщения

2. **Создайте рассылку:**
   - Нажмите "📤 Рассылка" → "📤 Новая рассылка"
   - Введите название рассылки
   - Введите текст сообщения
   - Выберите группу контактов (или "all" для всех)
   - Настройте задержку (например: 30-60 секунд)

3. **Запустите рассылку:**
   - Выберите рассылку из списка
   - Нажмите "▶️ Запустить"
   - Бот начнёт отправку с задержками

#### Управление контактами:

1. **Просмотр контактов:**
   - Нажмите "📋 Контакты" → "Все контакты"
   - Выберите контакт для просмотра деталей

2. **Отметка статуса:**
   - Выберите контакт
   - Нажмите кнопку статуса:
     - ✅ Написали
     - ❌ Не заинтересован
     - 🚫 Заблокировал
     - 🔄 Сбросить статус

3. **Фильтрация:**
   - 🟢 Активные - можно отправлять
   - ✅ Написанные - уже отправлено
   - ❌ Не заинтересованы - не отправлять
   - 🚫 Заблокировавшие - не отправлять

## ⚠️ Важные замечания

### Задержки между сообщениями

- **Минимальная рекомендуемая задержка:** 30 секунд
- **Telegram ограничивает:** ~30 сообщений в минуту
- **При превышении:** временный бан (flood wait)
- **Рекомендация:** 30-60 секунд между сообщениями

### Статусы контактов

- 🟢 **Активный** - можно отправлять сообщения
- ✅ **Написано** - уже отправлено сообщение
- ❌ **Не заинтересован** - не отправлять (попросил не писать)
- 🚫 **Заблокировал** - не отправлять (заблокировал бота)

### Безопасность

- Храните `.env` файл в секрете
- Не публикуйте токен бота
- Не публикуйте `credentials.json`
- Используйте только свои аккаунты

## 📊 Статистика

Бот отслеживает:
- Количество контактов по статусам
- Количество отправленных сообщений
- Процент успешных отправок
- Историю рассылок
- Время последнего контакта

## 🐛 Решение проблем

### Бот не отвечает

1. Проверьте токен в `.env`
2. Убедитесь, что бот запущен
3. Проверьте интернет-соединение
4. Посмотрите логи в консоли

### Ошибка "Not Found"

1. Токен неверный или устарел
2. Получите новый токен у @BotFather

### Flood Wait

1. Увеличьте задержку между сообщениями
2. Подождите указанное время
3. Уменьшите количество сообщений в день

### Не работает импорт из Google Sheets

1. Проверьте наличие `credentials.json`
2. Убедитесь, что таблица расшарена
3. Проверьте права доступа сервисного аккаунта
