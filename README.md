# 🚀 Telegram Sender Bot

Бот для рассылки сообщений в Telegram с управлением контактами и статистикой.

## 📋 Возможности

- ✅ Управление контактами (добавление, удаление, статусы)
- 📥 Импорт контактов из Google Sheets и CSV
- 📝 Создание шаблонов сообщений
- 📤 Запуск рассылок с настраиваемыми задержками
- 📊 Статистика и аналитика
- 👥 Множественные администраторы
- 🔔 Уведомления о статусе рассылок

## 🛠 Установка

### 1. Получите токен бота

1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте /newbot
4. Следуйте инструкциям
5. Скопируйте токен

### 2. Получите ваш Telegram ID

1. Найдите @userinfobot в Telegram
2. Отправьте /start
3. Скопируйте ваш ID

### 3. Настройте проект

```bash
# Склонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/tg_sender.git
cd tg_sender

# Скопируйте .env.example в .env
copy .env.example .env

# Отредактируйте .env файл
notepad .env
```

### 4. Запустите бота

**Windows:**
```bash
# Просто дважды кликните на start.bat
# Или запустите из командной строки:
start.bat
```

**Linux/Mac:**
```bash
# Создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt

# Запустите бота
python -m bot
```

## 📖 Использование

### Основные команды

- `/start` - Главное меню
- `/help` - Справка
- `/stats` - Быстрая статистика
- `/add_admin ID` - Добавить администратора (только для суперадмина)
- `/cancel` - Отмена текущего действия

### Работа с контактами

1. **Добавление контактов:**
   - Нажмите "📋 Контакты" → "➕ Добавить контакт"
   - Отправьте username: `@username` или `t.me/username`
   - Можно добавить несколько: каждый с новой строки

2. **Импорт из Google Sheets:**
   - Нажмите "📥 Импорт из Google Sheets"
   - Отправьте ссылку на таблицу
   - Таблица должна содержать столбцы: SSYLKA, NAME, OPISANIYE

3. **Импорт из CSV:**
   - Нажмите "📥 Импорт из CSV"
   - Отправьте CSV файл
   - Формат: username,name,description

4. **Отметка статуса:**
   - Выберите контакт из списка
   - Нажмите кнопку статуса:
     - ✅ Написали
     - ❌ Не заинтересован
     - 🚫 Заблокировал
     - 🔄 Сбросить статус

### Рассылка сообщений

1. **Создайте шаблон:**
   - Нажмите "📝 Шаблоны" → "➕ Создать шаблон"
   - Введите название и текст сообщения

2. **Создайте рассылку:**
   - Нажмите "📤 Рассылка" → "📤 Новая рассылка"
   - Введите название рассылки
   - Выберите шаблон сообщения
   - Выберите группу контактов
   - Настройте задержку (например: 30-60 секунд)

3. **Запустите рассылку:**
   - Выберите рассылку из списка
   - Нажмите "▶️ Запустить"
   - Бот начнёт отправку с задержками

## ⚠️ Важные замечания

1. **Задержки между сообщениями:**
   - Минимальная рекомендуемая задержка: 30 секунд
   - Telegram ограничивает: ~30 сообщений в минуту
   - При превышении - временный бан (flood wait)

2. **Статусы контактов:**
   - 🟢 Активный - можно отправлять
   - ✅ Написано - уже отправлено
   - ❌ Не заинтересован - не отправлять
   - 🚫 Заблокировал - не отправлять

3. **Безопасность:**
   - Храните .env файл в секрете
   - Не публикуйте токен бота
   - Используйте только свои аккаунты

## 📊 Статистика

Бот отслеживает:
- Количество контактов по статусам
- Количество отправленных сообщений
- Процент успешных отправок
- Историю рассылок

## 🐛 Решение проблем

**Бот не отвечает:**
- Проверьте токен в .env
- Убедитесь, что бот запущен
- Проверьте интернет-соединение

**Ошибка "Not Found":**
- Токен неверный или устарел
- Получите новый токен у @BotFather

**Flood Wait:**
- Увеличьте задержку между сообщениями
- Подождите указанное время
- Уменьшите количество сообщений в день
